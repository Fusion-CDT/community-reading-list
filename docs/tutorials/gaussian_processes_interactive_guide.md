This interactive tutorial introduces Gaussian Processes (GPs) from the underlying
probability distributions through to practical Gaussian Process regression in Scikit-learn.

The tutorial builds the concept progressively from:

1. The normal distribution
2. Multivariate normal distributions
3. Functions represented as vectors
4. Covariance matrices and kernel functions
5. The formal Gaussian Process definition
6. Gaussian Process regression
7. Hyperparameter optimisation

Interactive controls and plots are used throughout to illustrate how quantities
such as the mean, variance, covariance kernel, training data and hyperparameters
affect the resulting Gaussian Process Regression.

https://gaussianprocesses.streamlit.app/
